# LogArbiter Control Panel GUI:
- The LogArbiter Control Panel GUI is a  `Qt6`-based user-friendly interface that allows users to monitor and manage the behavior of the LogArbiter.

## Disclaimer:
- This GUI is purely **vibe-coded** , and is intended for demonstration purposes only.
  
## Features:
- **Log Monitoring**: Users can view and manage the logs generated by the LogArbiter, including filtering and searching.
- **Log Configuration**: Users can modify the configuration of the LogArbiter, such as the buffer capacity, sink flush rate, and thread pool size..etc.
- **Service Control**: Users can start and stop the LogArbiter services, such as the file generator, socket generator, and SomeIP server.
- **Empty Logs**: Users can clear the log files to start fresh.
